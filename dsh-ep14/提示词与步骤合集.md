> **官方 DeepSeek Harness Desktop（LIGHT UI）** · https://www.deepseek.com/download/

## 建议标题（3 选）
1. 进阶7：社区高阶插件甄别与实战
2. 非官方插件：先验再装
3. 读权限、看仓库、沙箱试跑

## 本集口播稿
1. 进阶终章！社区高阶插件——好用，但【非官方】，装之前必须会甄别。
2. 郑重声明：以下示范插件非 DeepSeek 官方维护。出问题以社区与作者为准。
3. 看来源：GitHub stars、最近提交、Issue 响应。一年没更新的谨慎。
4. 读 README 与权限列表：要不要读全盘？要不要联网？要不要改系统设置？
5. 先在干净工作区或临时账号试跑。能卸载、能回滚，再考虑日常使用。
6. 实战：挑一个文档清晰的社区插件，按作者步骤安装，完成一个最小用例。
7. 界面：安装前弹权限清单。不会读权限就点取消。
8. 示范：装一个社区文档插件，只开读权限，完成一次「生成周报」最小用例。
9. 前后对比：盲装图省事，验装多三分钟却能避开清盘风险。
10. 任何索要管理员或全盘读写的社区插件，默认拒绝。
11. 踩坑：别把 API Key 写进插件配置后上传；遇到索要管理员权限立刻停。
12. 复盘：声明非官方→验来源→读权限→沙箱→最小用例。这才是高阶用户的素养。
13. 进阶七集全部通关！回去把新手清单再过一遍，官方 UI 更新时记得对照下载页。
