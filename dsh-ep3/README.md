- **安全**：最小权限；拟议命令先过目

## 本集口播稿
1. 看！新建会话，选好文件夹，Agent 就开始按步骤干活啦～
2. 点 New Session。先挑一个工作区文件夹——没有工作区，它就像蒙着眼找文件。
3. 新手任务可以这样说：帮我阅读这个文件夹的 README，用中文写三句话介绍项目，直接改文件也可以。
4. 看时间线：它会读文件、列计划、再动手改。每一步都能展开看，觉得不对就暂停。
5. 比如它提出要运行终端命令，你会看到拟议命令卡片，确认后再执行，别一键全同意。
6. 安全习惯：只开放需要的文件夹，最小权限；敏感目录先别挂进去。
7. 小心踩坑！会话一直转圈卡住，多半是没选工作区。回去选个文件夹，再把任务发一次。
8. 第一次会话通关！步骤卡收好。下集教你写提示词，完成学习任务和小代码，拜拜～
