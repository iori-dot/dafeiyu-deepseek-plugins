## 本集口播稿
1. 看！DeepSeek 官方桌面端亮起来了——DeepSeek Harness，官网一键就能装！
2. 今天只教官方路径：打开 deepseek.com 斜杠 download，别去第三方「绿色版」哦～
3. Windows 下 dsh-latest-windows-x64 的 exe；Mac 苹果芯片下 dsh-latest-macos-arm64 的 dmg，系统要十三及以上。
4. Windows 双击安装；Mac 打开 dmg，把应用拖进「应用程序」。装好就能读写本地文件、后台跑长任务。
5. 小心踩坑！最常见是下到第三方「绿色版」或社区粉丝客户端。记住：只信 download.deepseek.com。
6. SmartScreen 或 Gatekeeper 拦你别慌——先核对是官网包。Win 点更多信息再仍要运行；Mac 访达里右键打开。
7. Linux 暂时没有官方桌面安装包。装好 Node 以后，一条命令：npx 空格 at deepseek-ai 斜杠 dsh web，就能开 Web 界面。
8. 官网安装通关！步骤卡收好。下集教你登录 DeepSeek 账号，或在设置里填开放平台 API Key，选 deepseek-flash，拜拜～
