## 平台下载速查
| 平台 | 包 |
| --- | --- |
| Windows x64 | NSIS 安装程序 |
| macOS | Universal DMG（Gatekeeper：右键 → 打开） |
| Linux | amd64 / arm64 `.deb`（亦见 GitHub Release 的 AppImage / tar.gz） |

## 召唤快捷键
默认 `Ctrl/Cmd + Shift + Space`（可在 Desktop settings 改）

## 数据目录
- Desktop 默认：`~/.dsh-desktop`
- CLI 常见：`~/.dsh`
