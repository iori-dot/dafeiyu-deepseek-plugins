# DSH 进阶系列 · 《Scheduler 定时任务》提示词与步骤合集

## 建议标题（3 选）
1. 进阶2：Scheduler 定时任务从 0 到 1
2. 定点执行：日报、备份、提醒
3. Harness 自动化：会排程才会省心

## 本集口播稿
1. 进阶第二集！Scheduler 定时任务——让 Harness 在你睡觉时也替你干活。
2. 打开 Automation / Scheduled tasks。这里能看到已有任务、下次运行时间和状态。
3. 新建任务：起个清晰名字，比如「每天早报」。绑定一个插件动作或脚本。
4. 周期可以选每天、每周，或写 cron 表达式。新手先用「每天九点」更稳。
5. 先点试跑。成功会有绿勾；失败立刻看日志，别等到夜里才发现空跑。
6. 日志面板记录每次触发、耗时和报错。排查时按时间倒序翻最近几条就够。
7. 界面：Scheduled tasks 列表里看名称、周期、下次运行。点进详情改参数。
8. 示范：每天九点生成工作区日报，失败自动重试一次并写日志。
9. 前后对比：手动提醒易忘，定时任务一眼看到下次开火时间。
10. 休眠与合盖可能跳过触发；重要任务配合开机或服务器侧调度。
11. 踩坑：时区要对齐本机；电脑睡眠可能跳过任务；敏感脚本别开过高权限。
12. 复盘：入口→新建→设周期→试跑→看日志。定时任务稳了，日常自动化就通了。
13. Scheduler 通关！下集讲 Skills 与 MCP——给智能体装外挂工具箱。
