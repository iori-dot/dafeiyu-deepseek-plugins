## 步骤清单
- **市场**：不必须；需要时手动装 dsh-market，核实第三方来源
- **飞书**：进阶提及，官方有接入路径
- **LAN**：默认本机；局域网无鉴权，勿随手开启
- **Safe Mode**：隔离用户插件，不删文件
- **Key**：永不进聊天/截图

## 本集口播稿
1. 恭喜！装好、配好、会聊、会写提示词——你已经能自己用 DSH 啦！
2. 插件市场不是第一天必须装的。要用扩展时，去 Settings 的 Desktop settings 里手动安装 dsh-market。
3. 装好后再进 Plugin Market 挑插件；第三方来源一定先核实，别装来路不明的包。
4. 飞书机器人有官方接入路径，属于进阶玩法；新手先把本机会话和提示词跑顺就好。
5. 重点警告：局域网开放默认没有鉴权！服务默认只听本机。别随手开到局域网，同网的人就能打开界面操作你的电脑。
6. API Key 永远别发聊天、别截进图。启动失败可以进 Safe Mode，它会隔离用户插件，但不会删你的文件。
