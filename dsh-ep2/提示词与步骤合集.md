# DSH 新手系列 · 《模型配置》提示词与步骤合集

> **官方 DeepSeek Harness Desktop（LIGHT UI）** · https://www.deepseek.com/download/

## 建议标题（3 选）
1. DSH 模型配置：登录账号 OR 填 API Key，选 deepseek-flash
2. Base URL 别乱加路径｜密钥只写不回显
3. 新手第2集：deepseek-flash = V4.1 Flash 1017

## 本集口播稿
1. 看！一发测试消息秒回——模型通啦！两条路都能走：登录账号，或者填开放平台 Key。
2. 左下角可以登录 DeepSeek 账号，浏览器授权回来就能用。不想登录也行，去设置，点模型。
3. 在设置箭头模型里，粘贴开放平台 API Key。密钥字段只写不回显，保存后界面看不到明文，这是正常的。
4. 填好点黑色的 Apply 保存。
5. 模型请选 deepseek-flash。它现在对应 DeepSeek-V4.1-Flash-1017，调用名还是 deepseek-flash，别手写一长串版本号。
6. Base URL 用官方默认即可；自定义时只写到 api.deepseek.com，后面别再拼 chat completions，客户端会自己补。
7. 小心踩坑！别把灰色占位文字整段粘进去，别把 Key 发到聊天或截进分享图。测通就发一句：请用一句话介绍你能帮我做什么。
8. 模型配置收好！下集带你第一次会话——先选工作区，再发小任务，拜拜～
