## 建议标题（3 选）
1. 进阶1：Creator Mode 对话造插件全流程
2. 官方创造模式：写包→安装→验证
3. DSH 高阶：番茄钟之外的自定义插件

## 本集口播稿
1. 进阶开场！今天专攻 Creator Mode——用对话把插件从零造出来，并装进官方 Harness Desktop。
2. 为什么要学它？官方插件不够用时，不必手搓脚手架，对话就能写 package、client、再一键安装。
3. 打开左侧 Plugins / Automation，找到实验性 Creator Mode 开关。启用前先读清风险提示。
4. 示范口令：给我写一个悬浮番茄钟插件，专注二十五分钟、短休息五分钟，装好后立刻可用。
5. 时间线会依次出现：加载技能、写 package.json、写 client 入口、调用 install_bundle。
6. 接着 Bash 验证：看进程是否起来、浮窗是否挂在主窗口。失败就回时间线看报错。
7. 造好后去 Plugins 列表找它，能开关、能卸载。右侧预览也能看到浮窗效果。
8. 界面对照：左侧 Plugins，中间对话，右侧时间线。新手跟着点高亮圆圈走就行。
9. 造完前后对比：以前只能装现成插件，现在对话一句话就能落盘安装。
10. 安全习惯：先在测试工作区试；确认无奇怪网络请求，再放进日常环境。
11. 踩坑提醒：实验功能可能破坏兼容；生成代码要扫权限；别对不明仓库一键安装。
12. 复盘：启用→口令→看时间线→列表验证。三步走完，你就拥有第一个自制插件。
13. Creator Mode 通关！下集把 Scheduled tasks 玩明白——定点交付、自动跑脚本。
