## 建议标题（3 选）
1. 进阶3：Skills + MCP 管理实战
2. 给模型接工具：文件系统、浏览器、API
3. 官方面板里装好技能与 MCP

## 本集口播稿
1. 进阶第三集！Skills 与 MCP——让模型不只会聊天，还能真正动手。
2. Skills 是可复用技能包：写文件、跑命令、调 API。在插件或设置里集中管理。
3. MCP 是模型上下文协议服务。接上后，智能体能访问你授权的外部工具。
4. 添加时优先选官方或可信源。填 endpoint、选传输方式，保存前核对名称。
5. 权限范围越小越好：只开需要的目录和接口。生产环境别给写死密钥进仓库。
6. 装完用一句简单指令验证，比如「列出当前工作区文件」。成功再接复杂流程。
7. 界面：Skills 列表与 MCP servers 分页。官方源带标记，社区源要小心。
8. 示范：接入一个只读文件系统 MCP，让模型列出工作区但不许删除。
9. 前后对比：纯聊天只能给建议；接上 Skills/MCP 才能真正改文件调工具。
10. 密钥放本机密钥链或环境变量，不要写进插件配置后提交 git。
11. 踩坑：重复装同名技能会冲突；MCP 断线先查网络与鉴权；别盲信社区配置。
12. 复盘：分清 Skills 与 MCP→可信源添加→收紧权限→小指令验证。
13. Skills 与 MCP 通关！下集 PTC 与子智能体——把大任务拆给小队去跑。
