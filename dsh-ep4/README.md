## 步骤清单
- **三件套**：目标 + 格式 + 约束（可加角色）
- **学习**：你是耐心的学习助教。把下面笔记讲给初中生听，再出 3 道问答题，格式必须是 Q：… A：…
- **代码**：用 Python 写一个读取成绩 CSV、求平均分的脚本。只要一个文件，关键行加注释，不要多余依赖。
- **万能**：你是什么角色，要完成什么，输出长什么样，不要做什么。

## 本集口播稿
1. 看！一张提示词，笔记整理完，小脚本也写好了！
2. 好提示词三件套：目标说清、输出格式说清、约束说清。别只丢一句「帮我弄弄」就走。
3. 角色也可以指定：你是耐心的学习助教，或你是严谨的代码搭档。
4. 学习任务示例：把下面这段笔记讲给初中生听，再出三道问答题，格式必须是 Q 冒号、A 冒号。
5. 代码任务示例：用 Python 写一个读取成绩 CSV、求平均分的脚本，只要一个文件，关键行加注释。
6. 两张任务跑完，提示词卡片弹出来啦——收藏起来，作业和代码都能复用！
7. 再记一句万能句式：你是什么角色，要完成什么，输出长什么样，不要做什么。
8. 提示词会写，Agent 就稳。下集讲插件与安全，系列收官，你已经快能自己用了，拜拜～
