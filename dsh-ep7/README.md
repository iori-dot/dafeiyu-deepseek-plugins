## 步骤清单

1. **托盘召唤**  
   窗口进托盘别慌。`Ctrl`（Windows/Linux）或 `Command`（Mac）+ `Shift` + `Space` 随时召唤；快捷键冲突就到 Settings 改。

2. **健康检查**  
   Settings → Desktop settings → 健康检查。默认**离线只读**，不会自动上传。报 issue 前可导出诊断包，**先脱敏**。

3. **Safe Mode**  
   启动失败点 Safe Mode：隔离用户插件，**不删文件**，方便排查是谁把启动搞挂了。

4. **日常小技巧**  
   - 新建会话先选工作区  
   - Key 永不进聊天截图  
   - 自定义 Base URL 只写到 `/v1`  
   - Agent 要跑命令先过一眼

5. **七集复盘**  
   安装 → API → 会话 → 提示词 → 插件安全 → 接常见软件 → 常用功能。步骤清单收藏慢慢练。
